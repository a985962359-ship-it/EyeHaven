# S013 小红帽去外婆家
系列：光光睡前小故事
年龄：3-6岁
来源：佩罗与格林公版情节，句子新写；软化
估时：约8分钟

小姑娘有一顶红丝绒帽子，天天戴着，大家都叫她「小红帽」。
这天，妈妈让她给生病的外婆送蛋糕和果酱，叮嘱道：「走大路，别贪玩，别和陌生人搭话。」
走到半路，路边的花开得正艳，一只大灰狼笑眯眯地凑过来：「小红帽，去哪儿呀？」小红帽忘了妈妈的话，老实回答：「去外婆家，就在三棵大橡树底下。」
大灰狼眼珠一转：「那边的花多好看，摘一束给外婆吧！」说完，它抄小路先跑了。
大灰狼敲开外婆的门，把外婆轻轻推进衣柜里关好，自己戴上外婆的帽子，躺进被窝。
小红帽抱着花来了，觉得今天的「外婆」怪怪的：「外婆，您的耳朵怎么这么大？」「为了听清你说话呀。」「外婆，您的眼睛怎么这么大？」「为了看清你呀！」「外婆，您的牙齿怎么这么大？」「为了——」
大灰狼刚要跳起来，门外传来樵夫叔叔的声音：「小红帽，是你吗？」大灰狼吓得从窗户逃走了。
外婆从衣柜里出来，抱着小红帽直喘气。小红帽说：「我以后一定记住妈妈的话，走大路，不跟陌生人说话。」

光光轻声说：「大人叮嘱的话，都是护身的小咒语。记住了，走到哪儿都不怕。晚安。」
