# S077 望梅止渴
系列：光光睡前小故事
年龄：3-6岁
来源：中国典故公版情节，句子新写；软化
估时：约8分钟

曹操带着大军赶路，正赶上大热天，太阳像个大火球。太阳晒得地面冒烟，水壶早就喝空了，士兵们个个口干舌燥，脚步越来越慢，有人一屁股坐在地上：「走不动啦，渴死啦！」
曹操心里着急：照这样下去，天黑也走不到有水的地方。
他骑在马上，擦了擦汗，往前看了看，忽然灵机一动，大声喊：「将士们！前面不远有一大片梅林，梅子结得又大又多，酸酸甜甜，咬一口，汁水直流！」
士兵们一听「梅子」，嘴里立刻冒出了口水，仿佛真的吃到了酸梅子。你一言我一语：「我最爱吃酸的！」「想想就流口水！」
说着说着，大家不觉得那么渴了，脚步也快了起来。
就这样，大军一鼓作气，翻过山坡，终于走到了有水源的地方。士兵们捧起清凉的水，咕咚咕咚喝了个痛快。
有个士兵笑着问曹操：「丞相，梅林在哪儿呢？」
曹操哈哈大笑：「梅林在心里！想着它，你们就走到了真正的水边。」
士兵们也笑了。原来，心里有个盼头，再难的路也能走下去。

光光轻声说：「心里想着甜甜的事，脚步就有力气。想着明天早上的煎蛋，睡吧，一觉就到啦。晚安。」
