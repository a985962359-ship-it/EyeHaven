# S033 司马光砸缸
系列：光光睡前小故事
年龄：3-6岁
来源：中国典故公版情节，句子新写；软化
估时：约8分钟

司马光小时候，聪明又冷静，常和小伙伴们在院子里玩捉迷藏。
院子里有一口大水缸，比孩子们还高，缸里装满了水，是留着浇花用的。缸沿上长满了青苔，滑溜溜的。
这天，一个小伙伴爬假山，脚下一滑，「扑通」掉进了大水缸！水一下子没过了他的头顶，他吓得直扑腾。
小伙伴们都慌了：有的哇哇大哭，有的转身跑去找大人，还有的站在原地直跺脚。
只有司马光没有慌。他想：「喊大人来，要跑好远，来不及了。得让水快点出来！」
他四下一看，搬起一块大石头，踮起脚，使出全身力气，「哐当」一声，把水缸砸出一个大洞！
水「哗哗」地涌出来，缸里的水越来越浅，小伙伴得救了，坐在地上直喘气。大人们闻声赶来，把他裹进干衣服里，喂了热汤，他很快就缓过来了，拉着司马光的手直说谢谢。
大家都夸司马光勇敢又冷静。司马光摇摇头说：「光着急没有用，得想办法。缸砸破了可以再买，人没事才最重要。」

光光轻声说：「遇到急事，先深呼吸，再想办法。你记住：大声喊大人，永远是对的。现在不着急啦，慢慢睡。晚安。」
