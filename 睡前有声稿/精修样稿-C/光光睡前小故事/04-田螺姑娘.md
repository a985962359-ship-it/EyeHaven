# 田螺姑娘
系列：光光睡前小故事（精修样稿）
年龄：6-8岁
来源：中国民间公版情节，句子新写
估时：约10分钟

年轻人谢端白天种田，夜里把碗洗得干干净净，扣在灶台上。河里他捡到一只大田螺，养在水缸里，当个安静的伴。
一连几天，他从田里回来，桌上竟有热饭。门没坏，村里没人认账。第三天他提前回家，躲在柴垛后。

水缸轻轻响。田螺壳裂开缝，走出一个姑娘，卷袖生火、淘米，米量得很准，像怕浪费。谢端出来。姑娘停住。
谢端说：「你若累，不必每天做。我自己会饿，也会熟。」
姑娘看了看他洗白的袖口：「我在河里听过你洗锅的声音。那声音很干净。我想让干净的人吃口热的。」

村里有人起哄，要看「神仙露原形」。姑娘不喜欢被围观。谢端把篱笆编严。后来仍有人逼。姑娘把螺壳捧给谢端：「壳还你。我不是展览。」她走回河里，水只响一下。

谢端把壳放回缸，依旧种田。热饭没了，他学会把米量准。夜里听河，河还是浅浅的。
光光讲完：「帮忙很好。被围着展览，可以走开。你也一样——今天的好，不必表演给所有人看。收进心里，去睡觉。」
灯暗。灶台在故事里，碗扣得整整齐齐。
