# 乌鸦喝水
系列：光光睡前小故事（精修样稿）
年龄：3-5岁
来源：伊索公版情节，句子新写
估时：约8分钟

天很干。乌鸦口渴，发现瓶子里有水，水面却在很下面。它把嘴伸进去，够不着。瓶子太硬，啄不破；太重，推不倒。
乌鸦急得叫了一声， hop 到旁边。地上有小石子。它忽然停住：「也许……」

它叼起一颗石子，丢进瓶里。水面晃一下，升一点点。再一颗，再一颗。瓶子渐渐响出细细的水声。终于，乌鸦喝到了。水很凉，它喝得很小心，怕洒。

旁边小麻雀问：「你为什么不喊别的鸟来帮你咬破瓶子？」
乌鸦说：「破了，水会流走。石子让水上来，瓶子还在。」

光光讲到这里，轻轻敲窗台：「遇到够不着的东西，可以想办法垫高、凑近，不一定非要砸坏。你困了也一样——不一定非要再玩一局，可以把眼睛闭上来。」
灯暗下去。瓶里的水，在故事里，已经够喝了。
