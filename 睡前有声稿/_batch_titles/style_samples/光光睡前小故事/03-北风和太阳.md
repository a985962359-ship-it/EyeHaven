# 北风和太阳
系列：光光睡前小故事（精修样稿）
年龄：3-5岁
来源：伊索公版情节，句子新写
估时：约8分钟

北风鼓着脸：「我最有本事。我一吹，什么都能滚开。」
太阳金灿灿：「比比看？路上有个行人穿着大衣。谁能让他把大衣脱掉，谁赢。」

北风先上。它用力吹，吹得树枝叫，吹得行人发抖。行人把大衣裹得更紧，扣子扣到下巴。北风越吹越猛，大衣越裹越死。北风没气了。
太阳不说话，只把阳光铺上去。路暖起来，行人额头出了薄汗。他松开扣子，再松开，最后把大衣搭在手臂上，找树荫走。

北风愣住：「我那么大力气……」
太阳说：「有时候，暖比猛管用。逼得太紧，人会抓得更牢。」

光光把灯调成暖黄色：「睡觉也像这样。逼自己『必须立刻睡着』，往往会更醒。把灯暖一点，身体松一点，困意自己会来。」
窗外若有风，让它吹树。人在被子里，不用跟风比力气。
