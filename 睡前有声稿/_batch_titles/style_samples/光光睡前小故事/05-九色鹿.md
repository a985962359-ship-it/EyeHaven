# 九色鹿
系列：光光睡前小故事（精修样稿）
年龄：6-8岁
来源：敦煌壁画故事公版情节，句子新写
估时：约10分钟

森林里有一头鹿，毛色像把彩虹轻轻收进灰里，不刺眼，可谁看过都忘不掉。人叫它九色鹿。
它曾救起一个落水的人。那人喘着气发誓：绝不说出鹿住在哪。九色鹿点头，消失在树影里。

国王的王后梦见九色鹿的皮。国王出重赏。落水的人摸着金子，又摸着自己的誓言，最后还是指了路。
箭对准森林。九色鹿走出来，没有逃。它对国王说：「你要的是一张皮。我救过的人，把路卖了。」
国王看着那人的脸。赏金忽然变得很吵。他放下弓。王后的梦还在，可梦不能大过誓言。

落水的人没有被写成最惨的结局——他只是被所有人看见了。被看见，有时比惩罚更重。
九色鹿回到林深处。毛色仍在，只是更少让人看见。不是所有宝物都该被请去宫殿。

光光把灯调暗：「答应过的事，比金子沉。你今晚若有一句诺言——比如刷完牙就躺下——也请守住。守住，灯会亮得很安静。」
林子在故事外很远。床在故事里很近。
