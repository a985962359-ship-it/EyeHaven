# 抗生素不是感冒药
系列：光光讲知识（精修样稿）
年龄：9-16岁
估时：约10分钟

哥哥发烧咳嗽，奶奶掏出以前剩下的「消炎药」：「先吃上，都是发炎。」
光光在桌边亮着灯，声音不凶，但很硬：「停一下。名字叫消炎，不代表能打所有不舒服。」

它在纸上画两个小人。「细菌像有细胞墙的小城。有的抗生素专门拆墙、断粮。病毒更像要钻进你细胞里复制的资料包——很多抗生素拆不到它的墙，因为那墙根本不存在。普通感冒、流感，多数是病毒。乱吃，等于对空气挥拳。」
哥哥哑着嗓子：「那黄鼻涕呢？网上说黄就是细菌。」
「颜色能提示，不能当判决。」光光说，「要不要用抗生素，听医生：看症状、病程，必要时化验。自己吃剩药，还有两个坏处——剂量不对；细菌可能学会躲药，下次真需要时不好使。」

奶奶把药瓶放回去，改成量体温、喝水、开窗。哥哥问：「那我是不是白难受？」
「难受是免疫系统在干活。该看医生就看，该休息就休息。药不是勇气，是工具——用错工具，墙拆不到，还可能伤到别的。」

夜里哥哥睡热睡，灯调暗。光光把纸条折好，边写着：病毒≠细菌；剩药≠处方。
它说：「这句话不暖哄哄，但真。真的才肯进灯。」
