# 洗手为什么比只冲水干净
系列：光光讲知识（精修样稿）
年龄：3-5岁
估时：约8分钟

晚饭前，苗苗从沙坑回来，手背上沾着灰。妈妈说洗手。苗苗把水龙头拧开，冲了三秒，甩一甩：「好了！」
光光从窗台探头：「灯说还没好。」
「水都冲过了呀。」
光光让她把手举到灯下。灰淡了，可指缝里还藏着一条黑线。「油和脏喜欢手。光冲水，它们会滑着不走。要请肥皂。」

苗苗挤了一点儿童皂，搓出泡沫。光光数拍子：「手心——手背——指缝——拇指——指尖——手腕。」苗苗笑：「像在跳舞。」
「对，泡沫跳舞，把油拉进水里，脏也跟着走。再冲干净，用毛巾擦干。」
冲完，指缝那条黑线没了。灯「叮」地亮了一下。

苗苗问：「那免洗的呢？」
光光说：「没水的时候可以用。手上有泥、有油，还是肥皂加水更踏实。」
开饭了。苗苗把椅子拉近，小声说：「今天我不让脏去吃饭。」
光光把灯调暗：「手洗干净了。肚子可以开工，眼睛可以准备睡觉。」
