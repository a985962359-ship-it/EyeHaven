# 光光有声稿（知识 + 故事 + 人物）

## 放在哪

- `光光讲知识/`：200 篇（幼儿园 3–6 岁 85 · 小学 7–12 岁 70 · 初中 13–15 岁 45）
- `光光睡前小故事/`：200 篇（同上年龄分配）
- `光光讲人物/`：36 篇人物小传（三段年龄各 12）
- App 书架：幼儿园 / 小学 / 初中；每段三本：讲知识、睡前小故事、讲人物
- `BedtimeCatalog.json`：进 App 的正文总表

## 写法（2026-9-23 起）

- **知识**：讲对、讲清楚；只做轻微睡前改写。不摘录《十万个为什么》等受版权保护正文。
- **故事**：伊索 / 格林 / 中国寓言神话等**公版情节核**，句子新写，吓人处软化。不采用迪士尼等仍受保护形象。
- **人物**：史实概述，句子原创，不抄现代传记书大段原文。
- 不再使用「假纸口袋 / 第X幕 / 同一套冒险壳」那种乱改法。
